# PoC 架构与核心工程验证报告 (Edge Audio Agent PoC)

## 1. 验证目标
在严格遵循 **“本地算力优先 (Edge-First)”** 原则下，验证：
1. **P0 动力安全与 4 音区越权拦截**（硬件级安全边界）；
2. **端侧物理不出车的本地偏好学习与持久化**（SQLiteCipher + 内存 Hot-Cache）；
3. **0 算力抢占的极速槽位路由耗时**（验证是否在微秒级完成，杜绝与自动泊车/感知算法争抢 NPU）。

---

## 2. 核心架构代码构成

| 文件路径 | 模块定位 | 核心工程设计与约束 |
| :--- | :--- | :--- |
| `poc/edge_audio_agent/agent_types.hpp` | 基础数据结构与类型定义 | 定义 4 音区枚举、P0~P2 意图安全域、槽位实体与调度决策结构体 |
| `poc/edge_audio_agent/local_memory_engine.hpp` | 端侧物理隔离记忆库 | 基于 SQLite (WAL模式) + 内存字典预热缓存，查表时延 < 100μs，断电原子安全 |
| `poc/edge_audio_agent/fast_slot_router.hpp` | C++ 极速静态槽位与意图分流器 | 0 NPU 依赖纯 CPU 轻量正则与意图路由，包含安全词熔断与音区权限校验 |
| `poc/edge_audio_agent/main.cpp` | 场景用例与压测驱动器 | 覆盖 6 大车规典型用例与 10,000 次决策耗时基准压测 |

---
