# AI-Native 设计编辑、手感调参（DialKit）与去 AI 味减法指南

> **对应技能**：`pm-design-editor`（唤醒指令：`/design sketch` / `/design dial` / `/design edit`）
> **方法论来源**：Shopify 产品设计工作室负责人 Marvin Schwaibold（Design Review 分享）及一流独立产品实践。

---

## 一、 为什么 AI 生成的界面一眼就有“廉价塑料味”？

当产品经理或独立开发者用 Codex、Claude Code 生成前端界面时，AI 极其擅长把需求文档里的每一个点都变成页面上的组件，但结果往往惨不忍睹：
1. **元素过载与注意力内战**：一个首屏摆出侧边栏、可滚动聊天窗、主标语外加 4 个同色高亮按钮，用户不知道先点哪里；
2. **傲慢的交互与平滑滚动**：AI 为了追求“高级感”，常擅自接管浏览器的原生滚动（Smooth Scroll），导致手指滑动页面时产生粘滞延迟，或者强迫用户等 500ms 缩回动画播完才能点下一张卡片；
3. **毫无意义的装饰插图**：每个小功能旁都配一个漂浮的小点或 SVG 动画，看似丰富，实则分散注意力，未能讲清产品机制；
4. **手感参数靠猜**：回弹力度、阻尼、模糊程度用自然语言反复修改 20 轮依然找不到感觉。

**破局原则**：AI 负责暴力穷举与实现，人类（PM / 独立开发者）必须退居**“总编辑 (Editor)”**席位，执行**草图降维 → 参数化控件调优 → 冷血减法**三步工作流。

## 二、 核心工作流：草图、调参、做减法

```
[粗糙草图/关键帧] ──► [AI 生成可打断交互] ──► [DialKit 滑块调参] ──► [冷血减法去 AI 味]
 (Figma/手绘/截图)     (随时可打断、不锁死)     (拖出最佳阻尼手感)     (只留 1 个主 CTA)
```

### 1. 草图降维沟通（Figma 只是草稿本）
当遇到复杂转场或状态交叉时，不要用几百字提示词跟 AI 描述“卡片点击展开后下方元素怎样避让”：
- 打开任意画板（Figma / Excalidraw / 纸笔拍照），画 3 个粗糙色块框（Frame 1: 未点击 ──► Frame 2: 点击中 ──► Frame 3: 打断后切向新色块）；
- 附带一条铁律投喂给 Agent：**“必须支持随时打断（Interruptible），动画未结束时点击另一个目标必须立刻响应并接管动效。”**

### 2. 手感参数化面板（DialKit 模式）
遇到动画弹性（`pullBoost`）、展开耗时（`duration`）、栅格间距（`gap`）等“一看就知道对不对，但用文字讲不清”的细节：
- 让 Agent 临时挂载一个右下角折叠的调试面板（Floating Sliders HUD）；
- 用 `<input type="range">` 实时联动 CSS 变量与动画常量；
- 亲手拖动滑块找到最丝滑的手感数值，点击“导出 Tokens”固化进正式代码，然后删掉临时调试面板。

### 3. 去 AI 味六条冷血减法红线
1. **单一主焦点 (Single Primary Action)**：首屏有且仅有 1 个高对比度按钮（Primary CTA），其余全部降级为文字链或次级幽灵按钮；
2. **绝不接管浏览器原生滚动**：删除一切人为控制加速度的平滑滚动脚本；
3. **砍掉 70% 的装饰性插图**：插图要么能直接讲清楚底层逻辑（信息图/真实界面截图），要么直接删掉留白；
4. **安静礼貌 (Polite UI)**：像走进别人房间一样安静，不主动弹窗、不闪烁索取注意力；
5. **只留 1 个 Showstopper**：全站集中精力打磨 1 个令人过目不忘的交互细节（如极致响应的报告抽屉或 3D 物理互动组件），其余保持极简克制；
6. **围绕主标语收拢布局**：如 Mintlify 式首屏——1 个干净标题 + 1 小段价值阐述 + 1 个显眼主按钮 + 1 张核心产品实景。

## 三、 提示词实战模板

### 模板 1：让 Agent 执行“去 AI 味冷血减法审计”
```markdown
请使用 `/design edit` 审查当前页面的 HTML/JSX 代码，执行冷血减法：
1. 找出所有互相抢夺注意力的同级彩色按钮，只保留 1 个最核心的 CTA，其余降级；
2. 检查是否存在劫持原生滚动、或动画期间锁定点击（不可打断）的代码，全部移除；
3. 删掉所有无助于解释产品机制的纯装饰性小图标与光斑背景；
4. 输出精简后的代码 diff。
```

### 模板 2：为交互组件注入 DialKit 手感调参条
```markdown
请使用 `/design dial` 为当前展开抽屉/列表组件注入一个右下角可折叠的临时参数面板：
- 控制参数：`transitionDuration` (80ms~500ms)、`springCurve`、卡片间距 `cardGap`；
- 要求滑块拖动时实时生效，并提供“复制最终 CSS 变量”按钮，方便定稿后移除调试面板。
```
